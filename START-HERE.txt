🚀 QUICK START - IKUTI LANGKAH INI:

┌──────────────────────────────────────────────────────────────────────────┐
│ STEP 1: Install Build Tools (SEKALI SAJA - 5-10 menit)                  │
└──────────────────────────────────────────────────────────────────────────┘

  1. Buka PowerShell sebagai ADMINISTRATOR
     (Klik kanan > Run as Administrator)

  2. Jalankan command ini:

     cd "C:\Sistem Pakar Web — Diagnosa Risiko Kecanduan HP pada Anak"
     .\install-build-tools.ps1

  3. Tunggu sampai selesai (5-10 menit)

  4. Tutup PowerShell Admin


┌──────────────────────────────────────────────────────────────────────────┐
│ STEP 2: Setup & Run Aplikasi                                            │
└──────────────────────────────────────────────────────────────────────────┘

  1. Buka PowerShell BARU (tidak perlu admin)

  2. Jalankan command ini:

     cd "C:\Sistem Pakar Web — Diagnosa Risiko Kecanduan HP pada Anak"
     .\setup-and-run.ps1

  3. Script akan otomatis:
     ✅ Install backend dependencies
     ✅ Setup database SQLite
     ✅ Seed data (15 symptoms, 16 rules)
     ✅ Install frontend dependencies
     ✅ Start servers (2 windows baru)

  4. Tunggu 30-60 detik, lalu buka browser:

     http://localhost:5173

┌──────────────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                          │
└──────────────────────────────────────────────────────────────────────────┘

  ❌ Script tidak bisa dijalankan?
     → Buka QUICK-START.md, ikuti "LANGKAH MANUAL"

  ❌ Error saat npm install?
     → Pastikan build tools sudah terinstall (STEP 1)
     → Cek SETUP.md untuk alternatif solusi

  ❌ Port sudah dipakai?
     → Kill process: netstat -ano | findstr :5000
     → Atau lihat QUICK-START.md bagian Troubleshooting
